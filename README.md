# 东方符卡战 · Touhou Spell Card Battle

基于《东方 Project》的联机符卡对战卡牌游戏。20 名角色，每人独立 HP、3 个技能、10 张符卡，配一套多层次的伤害/效果结算引擎。

## 快速开始

```bash
npm install

# 终端 1：启动对战服务器（WebSocket, 端口 8080）
npm run server

# 终端 2：启动网页客户端（Vite, 端口 5173）
npm run dev
```

浏览器打开 `http://localhost:5173`：

**联机对战**
1. 一名玩家点「创建房间」，得到 4 位房间码。
2. 另一名玩家输入房间码「加入」。
3. 双方各选角色 → 每回合**同时隐藏出牌** → 双方确认后揭示并结算。
4. 一方 HP 归零即分出胜负。

**单人模式**
- 点「单人模式」即可与简单人机对战，适合熟悉角色与规则。

> 远程联机：把服务器部署到公网主机，将客户端 `main.ts` 中的 `WS_URL` 指向该主机即可。

## 项目结构

```
packages/
├─ engine/          # 纯逻辑规则引擎（无 IO，可复现，权威结算）
│  ├─ src/
│  │  ├─ types.ts       核心类型 + 阶段钩子式效果系统
│  │  ├─ power.ts       威力计算 +X→翻倍→=X
│  │  ├─ damage.ts      伤害修正；免疫>至少/至多>反弹；吸收先物理后法术
│  │  ├─ priority.ts    优先级：发动无效>效果无效>反转>其余；同级按威力定先攻
│  │  ├─ effects.ts     原子效果库
│  │  ├─ buffs.ts       延时/持续 BUFF + 专属资源（奏数/面具/幻觉/元素…）
│  │  ├─ resolver.ts    回合结算主管线
│  │  ├─ game.ts        对局控制（合法着法/冷却/一次性符卡）
│  │  ├─ state.ts       状态/快照/历史（HP 回溯、逐回合伤害史）
│  │  └─ data/          20 名角色数据（_GUIDE.md 为录入规范）
│  └─ tests/            黄金用例 + 机制 + 冒烟
├─ server/          # Node + ws 权威服务器（房间/隐藏出牌/揭示/广播/单人 AI）
└─ client/          # Vite + TS 网页前端（选将/牌桌/日志/胜负/BGM）
```

## 规则要点（引擎实现）

- **威力对抗**：高威力 − 低威力 = 对低威力方的物理伤害。
- **伤害类型**：物理（威力差）/ 法术（符卡效果）。生命流失、吸收不属于伤害。
- **计算顺序**：威力与伤害均 **+X(加减) → 翻倍(乘除) → 变为X(赋值)**，小数向下取整。
- **伤害判定**：**免疫 > 至少/至多 > 反弹**；吸收护盾先抵物理再抵法术。
- **效果优先级**：**无效系 > 反转系 > 其余**；发动无效 > 效果无效；同级非无效系按威力高者先攻，威力相同再随机（日志标注）。BUFF/技能不受本回合无效系影响。
- **属性**：仅使用角色 HP 与技能；力/耐/灵/意/运为装饰。技能受各自「每N回合一次」冷却限制。
- **符卡**：每回合限 1 张，用过不可再用。
- **回合上限**：10 回合未分胜负时，血量高的一方获胜；血量相同则平局。

## 美术资源约定

- **角色立绘**：`packages/client/public/characters/{角色id}.png`（缺省时前端自动回退占位）。
- **符卡图标**：`packages/client/public/icons/{角色id}/{符卡id}.png|jpg|webp`，前端自动探测格式。
- **BGM**：`packages/client/public/bgm/{角色id}.mp3|ogg|wav`，开战时从双方角色中随机播放一人；缺失则静默跳过。
